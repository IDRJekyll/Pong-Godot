Python created Pong game with Godot.

Play-test the game: https://idrjekyll.github.io/Pong-Godot/

A simple game, with 2 options of play. Vs AI, and Player vs Player. Currently the game is only best of 9.

**Controls:**

Default & Player 1: **WASD**

Player 2 : **Arrow keys**

Learning python & game development at once. The game is pretty bare bones, and has only the most basic features that aren't polished the best. The idea is to continue learning python and how to build a game by making multiple simple small games that each go over different areas of development, and make a bigger game in the future.
